Lua（3）：函数、闭包与一等公民

Created2026-08-19|Updated2026-08-19|编程语言Lua
|Post Views:

函数是 Lua 的一等公民：能赋值、能传参、能返回、能存进表。再加上词法作用域带来的闭包，Lua 就能用极少的语法写出回调、状态机、生成器等结构，而不用引入复杂的类体系。这篇讲清楚函数相关的语法，以及闭包捕获变量的真实语义。

一、函数是一等值

二、多重返回值

函数可以返回多个值，调用处一一接收；在”表构造”里，最后一个是函数调用时会被自动展开：

多重返回值是非对称的：左边变量少于返回值时多余的被丢弃；函数调用若不在”最后一个位置”，也只返回第一个值。

四、命名参数：用表传参

参数多到 3 个以上时，传”选项表”比摆一长串位置参数更清晰，也更好加默认值。

五、闭包：捕获变量的引用

词法作用域下，内层函数可以访问外层局部变量；这些外层局部变量叫 upvalue。关键点是：闭包捕获的是变量本身（引用），不是它的快照。

闭包最常见的用处是”把数据和行为封装在一起”，比手动传参更内聚：

一个细节：循环里创建闭包时，upvalue 是”共享”的那个循环变量，容易踩坑：

Lua 5.4 起，数值型 for 每次迭代都会创建新的循环变量，闭包能各取所需。但在 Lua 5.1~5.3 与 LuaJIT 里，循环变量是同一个，所有闭包共享它，结果会全部等于循环结束后的最终值——老代码里”一堆回调全是最后一个元素”的 bug 多半就来自这里。

六、尾调用：栈不增长的递归

当函数最后一次动作是 return f(args) 时，Lua 会做尾调用优化（TCO），不再为新调用压栈：

尾调用要求满足两点：必须是”return 一个函数调用”，并且是该函数的最后一个语句。注意 TCO 会丢弃调用方的栈帧信息，用 debug 看调用链时看不到中间帧，排查递归时心里要有数。

七、实战：用函数表做状态机

把”状态”映射成”函数”，是 Lua 里最典型、也最省性能的状态机写法（不必每个状态都建对象）：

自查清单

  • 理解函数是一等值，能赋值、传参、存表、返回
  • 能说清多重返回值的展开规则（含表构造里的展开）
  • 会用 ... + select("#") + table.pack 处理可变参数
  • 理解闭包捕获的是变量引用；能在循环里正确复制 upvalue
  • 会写尾递归，并知道 TCO 会丢调用栈帧
