Unity Shader（10）：屏幕后处理与 URP 自定义 Renderer Feature

Created2026-08-13|Updated2026-08-17|UnityShader
|Post Views:

前面都是”改一个物体”，这一讲开始”改整个画面”。屏幕后处理（Post-Processing）的原理是：先把场景渲染到一张纹理，再拿这张纹理做全屏处理，最后输出到屏幕。本文讲清这个原理，对比 Built-in 与 URP 的做法，并手写一个 URP 自定义 Renderer Feature 的灰度滤镜作为完整示例。

一、屏幕后处理的原理

普通渲染是”物体 → 帧缓冲 → 屏幕”；后处理多了一步”先渲染到纹理，再处理”：

场景渲染 → 中间纹理（颜色缓冲）→ 全屏 Shader 处理 → 屏幕
```text

那个"全屏 Shader"跑在一个铺满屏幕的四边形上，输入就是中间纹理，输出是最终画面。所以后处理 Shader 的结构和上一讲 Image Effect 模板一致：`Cull Off ZWrite Off ZTest Always`。

## 二、Built-in 的做法

Built-in 下做后处理，典型是 C# 挂脚本 + `OnRenderImage`：

```csharp
public class GrayScale : MonoBehaviour
{
    public Material material;

    void OnRenderImage(RenderTexture src, RenderTexture dst)
    {
        Graphics.Blit(src, dst, material); // 用 material 处理 src 并输出到 dst
    }
}
```text

配一个上一讲讲过的 Image Effect Shader 即可。另外 `GrabPass` 可以在渲染物体时"抓取当前画面"，适合折射、玻璃等局部效果，但它是 Built-in 概念，URP 下用别的方式实现。

## 三、URP 的后处理体系

URP 把后处理分成两条路：

| 方式 | 是什么 | 适合 |
| :--- | :--- | :--- |
| **Volume（内置后处理）** | Bloom、Tonemapping、Vignette 等现成效果 | 常用效果，勾选即用 |
| **Renderer Feature（自定义）** | 自己写 Pass 插入渲染流程 | 灰度、描边、自定义滤镜 |

内置后处理：在 Renderer 资源里勾选 `Post Processing`，相机勾选 `Post Processing`，再在场景里加 `Volume`，即可叠加 Bloom 等效果——这部分是"用现成的"，不是本文重点。

**Renderer Feature** 才是"自己写后处理"的正道：你写一个 `ScriptableRendererFeature` + `ScriptableRenderPass`，把它挂到 URP Renderer 资源上，它就会在你指定的时机插入渲染流程。

## 四、手写一个灰度 Renderer Feature

下面做一个完整的最小示例：一个灰度全屏 Shader + 一个 Pass + 一个 Feature。跑通它，你就能照葫芦画瓢写任意后处理。

### 4.1 全屏 Shader

```hlsl
Shader "Hidden/GrayScale"
{
    SubShader
    {
        Cull Off ZWrite Off ZTest Always

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            TEXTURE2D(_BlitTexture);
            SAMPLER(sampler_BlitTexture);

            struct Attributes { float4 positionOS : POSITION; float2 uv : TEXCOORD0; };
            struct Varyings   { float4 positionHCS : SV_POSITION; float2 uv : TEXCOORD0; };

            Varyings vert(Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag(Varyings IN) : SV_Target
            {
                half4 col = SAMPLE_TEXTURE2D(_BlitTexture, sampler_BlitTexture, IN.uv);
                half gray = dot(col.rgb, half3(0.299, 0.587, 0.114));
                return half4(gray.xxx, col.a);
            }
            ENDHLSL
        }
    }
}
```text

要点：
- `_BlitTexture` 是 URP Blit 传进来的源纹理（旧版 URP 曾用 `_MainTex`，若采样结果全黑，检查这个属性名）。
- 灰度公式用亮度权重 `(0.299, 0.587, 0.114)`，符合人眼对不同颜色的敏感度。

### 4.2 渲染 Pass

```csharp
using UnityEngine;
using UnityEngine.Rendering;
using UnityEngine.Rendering.Universal;

public class GrayScalePass : ScriptableRenderPass
{
    private Material material;
    private int tempRTId = Shader.PropertyToID("_TempGrayScale");

    public GrayScalePass(Material material)
    {
        this.material = material;
    }

    public override void Execute(ScriptableRenderContext context, ref RenderingData renderingData)
    {
        CommandBuffer cmd = CommandBufferPool.Get();
        RenderTargetIdentifier source = renderingData.cameraData.renderer.cameraColorTarget;
        RenderTextureDescriptor descriptor = renderingData.cameraData.cameraTargetDescriptor;

        cmd.GetTemporaryRT(tempRTId, descriptor);
        Blit(cmd, source, tempRTId, material); // 原画面 → 临时纹理（经灰度处理）
        Blit(cmd, tempRTId, source);            // 临时纹理 → 屏幕
        context.ExecuteCommandBuffer(cmd);
        CommandBufferPool.Release(cmd);
    }

    public override void OnCameraCleanup(CommandBuffer cmd)
    {
        cmd.ReleaseTemporaryRT(tempRTId);
    }
}
```text

`Execute` 的套路是固定的：拿当前相机颜色目标 → 用临时纹理做中转 → 经过 Shader 处理后写回屏幕。

### 4.3 渲染 Feature

```csharp
using UnityEngine;
using UnityEngine.Rendering;
using UnityEngine.Rendering.Universal;

public class GrayScaleFeature : ScriptableRendererFeature
{
    public Material material;
    private GrayScalePass pass;

    public override void Create()
    {
        pass = new GrayScalePass(material);
        pass.renderPassEvent = RenderPassEvent.AfterRenderingOpaques; // 不透明物体画完后执行
    }

    public override void AddRenderPasses(ScriptableRenderer renderer, ref RenderingData renderingData)
    {
        if (material != null)
            renderer.EnqueuePass(pass);
    }
}
```text

### 4.4 接线步骤

1. 把上面三样放好：Shader、`GrayScalePass.cs`、`GrayScaleFeature.cs`。
2. 创建一个 Material 用 `Hidden/GrayScale` Shader。
3. 打开 URP Renderer 资源，点 `Add Renderer Feature → Gray Scale Feature`，把 Material 拖进去。
4. 场景变灰即成功。

`renderPassEvent` 决定插入时机，常用值：

| 时机 | 含义 |
| :--- | :--- |
| `AfterRenderingOpaques` | 不透明画完、半透明之前（多数后处理放这里） |
| `AfterRenderingTransparents` | 半透明之后 |
| `BeforeRenderingPostProcessing` | 内置后处理之前 |

## 五、Full Screen Shader Graph

Unity 2022.2+ 提供了 **Full Screen Shader Graph**，配合 **Full Screen Pass Renderer Feature** 使用，让你用连线（而非 C#）做全屏后处理。原理和上面完全一致，只是把"写 Pass + Feature"封装成了模板。适合不写 C# 的团队。
