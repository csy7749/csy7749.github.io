Unity Shader（8）：透明、混合、剔除与渲染队列

Created2026-08-13|Updated2026-08-18|UnityShader
|Post Views:

半透明玻璃、粒子特效、水面，都靠四个”开关”配合：Cull（剔除哪面）、ZWrite/ZTest（深度怎么处理）、Blend（颜色怎么混合）、Queue（什么时候画）。这四个开关组合错了，就会出现”透明物体挡住后面的东西””半透明变黑边”这类经典 bug。本文把它们一个个讲透，并给出标准透明 Shader 与镂空 Shader 的完整写法。

一、Cull：剔除哪一面

GPU 默认只画”朝向相机”的面（背面剔除），以省一半工作量。Cull 控制剔除哪一面：

值 含义 用途
Cull Back 剔除背面（默认） 普通闭合网格
Cull Front 剔除正面 特殊效果、内部视角
Cull Off 不剔除，双面渲染 树叶、布料、水面、描边壳

透明物体经常要 Cull Off，因为你会看到它的”背面”（比如玻璃瓶的内壁、纸张的另一面）。

二、ZWrite / ZTest：深度写入与深度测试

深度缓冲记录”离相机最近的点有多远”，用来决定谁挡住谁。

  • ZTest：拿当前片元的深度和深度缓冲比较，通过才继续。默认 LEqual（小于等于则通过，即”更近或相等就画”）。
  • ZWrite：这个片元通过后，要不要把自己的深度写进深度缓冲。默认 On。

为什么半透明物体要 ZWrite Off？因为它不能挡住后面的东西——后面物体的颜色要”透”出来。但它自己又需要被前面的不透明物体遮挡，所以 ZTest 保持 LEqual。

这是半透明最经典的一对设置：ZWrite Off（不写深度，避免挡住别人）+ ZTest LEqual（仍被不透明物体正确遮挡）。

三、Blend：颜色怎么混合

Blend 定义新片元颜色（Src）和帧缓冲已有颜色（Dst）如何相加：

常见写法：

写法 公式 效果
Blend SrcAlpha OneMinusSrcAlpha Src×α + Dst×(1−α) 标准 Alpha 混合（半透明）
Blend One One Src + Dst 加法混合（光效、火、能量）
Blend One Zero Src 完全不透明（默认）
Blend Zero SrcColor Dst×Src 乘法混合（变暗、阴影）

其中 SrcAlpha OneMinusSrcAlpha 是最常用的：α=1 完全覆盖，α=0.5 各占一半，α=0 完全透明。

四、渲染队列 Queue：决定绘制顺序

不透明物体无所谓顺序（深度缓冲会兜底），但半透明物体必须从远到近绘制，否则混合结果错误。Unity 用 Queue 控制先后：

队列 数值 内容
Background 1000 天空盒、背景
Geometry 2000 不透明物体（默认）
AlphaTest 2450 镂空（Clip）物体
Transparent 3000 半透明物体（从远到近）
Overlay 4000 最后绘制（镜头光晕等）

半透明 Shader 必须写：

数值越大越晚画。半透明物体内部仍按”距离相机由远到近”排序，这是 GPU 层面保证的。

五、标准透明 Shader（Built-in）

三个开关各司其职：Blend 决定半透明混合，ZWrite Off 保证不挡住背后物体，Cull Off 让两面都可见。

六、镂空 Shader：透明与不透明的折中

镂空（Cutout）不搞”半透明混合”，而是直接丢弃某些像素。它保留深度写入，所以排序简单、渲染便宜：

clip(x) 在 x < 0 时丢弃该片元。镂空常用于树叶、栅栏、镂空贴纸——边缘是”硬”的，没有半透明过渡，但性能更好、不会排序错乱。

七、URP 下的对应关系

URP 手写 HLSL 时，透明相关写法基本一致（Blend / ZWrite / Cull 是 ShaderLab 层，不随管线变）。用 Shader Graph 则直接在属性里切：

  • Surface Type 选 Transparent → 自动生成 Blend SrcAlpha OneMinusSrcAlpha + ZWrite Off。
  • 勾选 Alpha Clipping → 生成 clip，对应镂空。

也就是说，URP 只是把这些底层开关”封装成了面板选项”，底层还是本讲讲的这四样。

八、自查清单

  • 能说出 Cull Back / Front / Off 的差异与使用场景
  • 知道半透明为什么要 ZWrite Off 但保留 ZTest LEqual
  • 能默写标准 Alpha 混合 Blend SrcAlpha OneMinusSrcAlpha 的公式
  • 知道加法混合 Blend One One 的用途
  • 能按数值排出 Background/Geometry/AlphaTest/Transparent/Overlay 的顺序
  • 知道半透明物体的绘制顺序要求，以及镂空的优势
  • 能写出 clip(col.a - _Cutoff) 并解释其作用
