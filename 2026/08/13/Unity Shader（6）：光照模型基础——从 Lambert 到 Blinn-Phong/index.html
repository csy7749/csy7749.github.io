Unity Shader（6）：光照模型基础——从 Lambert 到 Blinn-Phong

Created2026-08-13|Updated2026-08-17|UnityShader
|Post Views:

物体”看起来像 3D”，靠的是明暗变化。这一讲进入 Shader 最核心的部分：光照。我们从光的三要素（环境光、漫反射、高光）讲起，推导 Lambert 与 Half-Lambert 漫反射、Blinn-Phong 高光，最后给一个完整可运行的 Shader，并说明 URP 下光照写法如何变化。看完这篇，你会理解那句贯穿 Shader 的代码——saturate(dot(N, L)) 到底在算什么。

一、光照的三大组成

一个像素的最终颜色，通常由三部分拼起来：

最终颜色 = 环境光 + 漫反射 + 高光
```text

| 组成 | 特点 | 与视角有关 |
| :--- | :--- | :--- |
| 环境光（Ambient） | 各处均匀，物体阴影里也有光 | 否 |
| 漫反射（Diffuse） | 光打到粗糙表面均匀散射，明暗随角度变化 | 否 |
| 高光（Specular） | 光滑表面的镜面亮点 | 是 |

后面所有光照 Shader，本质上都是把这三项算出来再加起来。

## 二、漫反射：Lambert 模型

Lambert 定律：**表面接收的光能，正比于光照方向与表面法线的夹角余弦**。

```text
L = 指向光源的方向（单位向量）
N = 表面法线（单位向量）
diffuse = lightColor * albedo * saturate(dot(N, L))
```text

`dot(N, L)` 是两个单位向量的点积，等于它们夹角的余弦：

- N 与 L 同向（正对光源）→ 点积为 1 → 最亮
- N 与 L 垂直 → 点积为 0 → 无漫反射
- N 与 L 反向（背对光源）→ 点积为负 → 被 `saturate` 夹成 0

所以漫反射就是：

```hlsl
float NdotL = saturate(dot(N, L));
fixed3 diffuse = _LightColor0.rgb * albedo * NdotL;
```text

## 三、Half-Lambert：让暗部不死黑

标准 Lambert 有个问题：背光的一半是纯黑，暗部细节全没了。Valve 在《半条命》里提出的 **Half-Lambert** 把点积从 [-1,1] 映射到 [0,1]：

```hlsl
// 标准 Lambert：暗部 = 0
float NdotL = saturate(dot(N, L));

// Half-Lambert：暗部被提亮
float NdotL = dot(N, L) * 0.5 + 0.5;
```text

对照：

| 夹角 | 标准 Lambert | Half-Lambert |
| :--- | :--- | :--- |
| 正对（dot=1） | 1 | 1 |
| 垂直（dot=0） | 0 | 0.5 |
| 背对（dot=-1） | 0 | 0 |

Half-Lambert 常用于**卡通渲染、手游角色**，让暗部通透不死黑，缺点是物理上不准确。

## 四、高光：Blinn-Phong 模型

高光模拟的是"光源在光滑表面的镜面反射"。Blinn-Phong 的巧妙之处在于引入**半程向量 H**：

```text
V = 从表面指向相机的视线方向
L = 指向光源的方向
H = normalize(L + V)   ← 半程向量：L 和 V 的角平分线
specular = lightColor * specColor * pow(saturate(dot(N, H)), gloss)
```text

- 当 H 与法线 N 重合时（dot=1），说明"反射方向正好对准相机"，高光最强。
- `pow(..., gloss)` 的指数控制高光光斑大小：指数越大，高光越集中、越锐利。

```hlsl
float3 H = normalize(L + V);
float NdotH = saturate(dot(N, H));
fixed3 specular = _LightColor0.rgb * _SpecColor.rgb * pow(NdotH, _Gloss);
```text

## 五、逐顶点 vs 逐片元

光照计算可以放在顶点着色器，也可以放在片元着色器：

| 方式 | 计算位置 | 效果 | 性能 |
| :--- | :--- | :--- | :--- |
| 逐顶点（Gouraud） | vert 里算颜色 | 低面数时高光块状、有折痕 | 省 |
| 逐片元（Phong/Blinn-Phong） | frag 里算颜色 | 平滑自然 | 贵（现代默认） |

因为片元数远多于顶点数，逐片元贵；但现代硬件完全扛得住，所以**除非做超低端优化，否则默认逐片元**。逐顶点光照主要用于"顶点颜色当光照结果"这类特殊场合。

## 六、完整 Shader（Built-in）

```hlsl
Shader "Tutorial/LambertBlinnPhong"
{
    Properties
    {
        _MainTex ("Albedo", 2D) = "white" {}
        _Gloss ("Gloss", Range(1, 256)) = 32
        _SpecColor ("Specular Color", Color) = (1,1,1,1)
    }

    SubShader
    {
        Tags { "RenderType"="Opaque" }

        Pass
        {
            Tags { "LightMode"="ForwardBase" }

            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"
            #include "Lighting.cginc"

            sampler2D _MainTex;
            float4 _MainTex_ST;
            half _Gloss;
            fixed4 _SpecColor;

            struct appdata
            {
                float4 vertex : POSITION;
                float3 normal : NORMAL;
                float2 uv     : TEXCOORD0;
            };

            struct v2f
            {
                float4 pos        : SV_POSITION;
                float2 uv         : TEXCOORD0;
                float3 worldNormal : TEXCOORD1;
                float3 worldPos   : TEXCOORD2;
            };

            v2f vert (appdata v)
            {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.uv = TRANSFORM_TEX(v.uv, _MainTex);
                o.worldNormal = UnityObjectToWorldNormal(v.normal);
                o.worldPos = mul(unity_ObjectToWorld, v.vertex).xyz;
                return o;
            }

            fixed4 frag (v2f i) : SV_Target
            {
                fixed4 albedo = tex2D(_MainTex, i.uv);

                float3 N = normalize(i.worldNormal);
                float3 L = normalize(UnityWorldSpaceLightDir(i.worldPos));
                float3 V = normalize(UnityWorldSpaceViewDir(i.worldPos));
                float3 H = normalize(L + V);

                // 环境光
                fixed3 ambient = UNITY_LIGHTMODEL_AMBIENT.xyz * albedo.rgb;

                // Lambert 漫反射
                float NdotL = saturate(dot(N, L));
                fixed3 diffuse = _LightColor0.rgb * albedo.rgb * NdotL;

                // Blinn-Phong 高光
                float NdotH = saturate(dot(N, H));
                fixed3 specular = _LightColor0.rgb * _SpecColor.rgb * pow(NdotH, _Gloss);

                return fixed4(ambient + diffuse + specular, 1.0);
            }
            ENDCG
        }
    }

    Fallback "Diffuse"
}
```text

### 6.1 关键点说明

- `LightMode` 写错了会取不到光照，正确值是 `ForwardBase`（Built-in 前向渲染的主光源 Pass）。
- `_LightColor0`：主光源颜色（Built-in 内置变量，需 `Lighting.cginc`）。
- `UNITY_LIGHTMODEL_AMBIENT`：场景环境光。
- `UnityWorldSpaceLightDir(pos)` / `UnityWorldSpaceViewDir(pos)`：求世界空间光照/视线方向。
- 把 `NdotL` 换成 `dot(N,L)*0.5+0.5`，就是 Half-Lambert 版本。

## 七、URP 下的光照写法

URP 没有 `_LightColor0` 和 `UnityWorldSpaceLightDir` 这套老变量，改用 `GetMainLight()`：

```hlsl
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Lighting.hlsl"

// frag 里：
Light mainLight = GetMainLight();
float3 L = mainLight.direction;
half3 lightColor = mainLight.color;

float NdotL = saturate(dot(N, L));
half3 diffuse = lightColor * albedo.rgb * NdotL;
```text

差异总结：

| 事项 | Built-in | URP |
| :--- | :--- | :--- |
| 主光源方向 | `UnityWorldSpaceLightDir(pos)` | `GetMainLight().direction` |
| 主光源颜色 | `_LightColor0.rgb` | `GetMainLight().color` |
| 环境光 | `UNITY_LIGHTMODEL_AMBIENT` | `SampleSH(normal)`（球谐光照） |
| 法线变换 | `UnityObjectToWorldNormal` | `TransformObjectToWorldNormal` |
