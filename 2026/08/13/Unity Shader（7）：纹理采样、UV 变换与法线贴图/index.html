Unity Shader（7）：纹理采样、UV 变换与法线贴图

Created2026-08-13|Updated2026-08-17|UnityShader
|Post Views:

真实感的一半来自贴图。这一讲深入纹理的三个层面：怎么按 UV 采样、怎么自由变换 UV 做出各种图案效果、以及最常用的法线贴图——它为什么是蓝紫色的、切线空间 TBN 是什么。文末给一个完整的法线贴图 Shader。学完这篇，你能读懂绝大多数”贴图+凹凸”类代码。

一、UV 坐标与采样器

  • UV 坐标：把 3D 表面展平到 2D 纹理上的坐标，范围通常是 [0,1]，(0,0) 在纹理左下角。
  • 采样（Sampling）：按 UV 去纹理里取对应像素的颜色。内置管线用 tex2D，URP 用 SAMPLE_TEXTURE2D。
// Built-in
fixed4 col = tex2D(_MainTex, i.uv);
// URP
half4 col = SAMPLE_TEXTURE2D(_MainTex, sampler_MainTex, i.uv);
```text

## 二、Tiling / Offset 是怎么实现的

材质面板上的 Tiling（平铺）和 Offset（偏移），底层就是一个 UV 线性变换。Unity 自动生成 `_MainTex_ST`（ST = Scale&Translate）：

```hlsl
// 等价于材质面板 Tiling=xy、Offset=zw
uv = v.uv * _MainTex_ST.xy + _MainTex_ST.zw;
```text

内置宏 `TRANSFORM_TEX(v.uv, _MainTex)` 就是上面这行的缩写。这就是为什么你在 Shader 里总看到它——少了它，材质面板的 Tiling/Offset 就失效。

## 三、UV 变换：做出各种图案

既然 UV 就是一个二维坐标，那所有"平面几何变换"都能套在它上面。

### 3.1 平移与缩放

```hlsl
float2 uv = i.uv;
uv = uv * 2.0;          // 缩放：图案重复 2 次
uv = uv + float2(0.5, 0); // 平移：整体偏移
```text

### 3.2 旋转（绕中心）

```hlsl
float2 RotateUV(float2 uv, float angle)
{
    float s = sin(angle);
    float c = cos(angle);
    uv -= 0.5;                        // 移到中心
    uv = float2(uv.x * c - uv.y * s,
                uv.x * s + uv.y * c); // 旋转
    uv += 0.5;                        // 移回
    return uv;
}
```text

### 3.3 极坐标：做漩涡、放射状图案

```hlsl
float2 centered = i.uv - 0.5;
float radius = length(centered) * 2.0;
float angle  = atan2(centered.y, centered.x);
float2 polarUV = float2(radius, angle / (2.0 * 3.14159265));
```text

把直角坐标换成"距离+角度"，再用它采样，就能得到放射状或漩涡图案。UV 变换是"程序化图案"的起点：棋盘格、渐变、噪声，本质都是对 UV 做数学。

## 四、法线贴图：为什么是蓝紫色

### 4.1 它存的是什么

法线贴图（Normal Map）里存的是**每个像素的法线方向**，RGB 三个通道分别编码法线的 X、Y、Z 分量。

- R 通道 → 切线方向（左右）
- G 通道 → 副切线方向（上下）
- B 通道 → 表面法线（前后）

**为什么整体偏蓝紫**：默认"平坦"表面的法线是 `(0, 0, 1)`，映射到颜色 `(0.5, 0.5, 1.0)` 就是蓝紫色。只有表面凹凸不平的地方才会偏红、偏绿。

### 4.2 切线空间

法线贴图记录的法线，是相对于**每个像素自己的局部坐标系**的，这个坐标系叫**切线空间（Tangent Space）**：

- **T（切线 Tangent）**：沿着表面 U 方向
- **B（副切线 Bitangent）**：沿着表面 V 方向
- **N（法线 Normal）**：垂直表面

用切线空间的好处：贴图可以贴在任意朝向的表面上，甚至给动画中的角色复用。

### 4.3 从贴图读到真实法线

法线贴图里的值范围是 [0,1]，要先映射回 [-1,1]：

```hlsl
// Unity 内置的 UnpackNormal 就是做这件事
fixed3 tangentNormal = UnpackNormal(tex2D(_BumpMap, uv));
// 等价于：tangentNormal.xyz = tex * 2 - 1
```text

## 五、TBN 矩阵：把法线从切线空间转到世界空间

光照计算要在**同一个空间**进行。我们通常在世界空间算光照，所以需要把切线空间的法线转到世界空间，用的就是 **TBN 矩阵**：

```text
TBN = [ T  B  N ]   （三列分别是切线、副切线、法线）
worldNormal = mul(TBN, tangentNormal)
```text

求 B 最常用的方式：

```hlsl
float3 worldNormal = UnityObjectToWorldNormal(v.normal);
float3 worldTangent = UnityObjectToWorldDir(v.tangent.xyz);
float3 worldBinormal = cross(worldNormal, worldTangent) * v.tangent.w;
```text

`v.tangent.w` 是切线的手性（±1），用来纠正副切线方向，避免镜像 UV 的模型法线贴图左右颠倒。

## 六、完整法线贴图 Shader（Built-in）

```hlsl
Shader "Tutorial/NormalMap"
{
    Properties
    {
        _MainTex ("Albedo", 2D) = "white" {}
        _BumpMap ("Normal Map", 2D) = "bump" {}
        _BumpScale ("Bump Scale", Float) = 1.0
    }

    SubShader
    {
        Tags { "RenderType"="Opaque" }

        Pass
        {
            Tags { "LightMode"="ForwardBase" }

            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"
            #include "Lighting.cginc"

            sampler2D _MainTex;
            float4 _MainTex_ST;
            sampler2D _BumpMap;
            float4 _BumpMap_ST;
            float _BumpScale;

            struct appdata
            {
                float4 vertex  : POSITION;
                float3 normal  : NORMAL;
                float4 tangent : TANGENT;
                float2 uv      : TEXCOORD0;
            };

            struct v2f
            {
                float4 pos  : SV_POSITION;
                float4 uv   : TEXCOORD0; // xy=主贴图, zw=法线贴图
                float4 TtoW0 : TEXCOORD1;
                float4 TtoW1 : TEXCOORD2;
                float4 TtoW2 : TEXCOORD3;
            };

            v2f vert (appdata v)
            {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.uv.xy = TRANSFORM_TEX(v.uv, _MainTex);
                o.uv.zw = TRANSFORM_TEX(v.uv, _BumpMap);

                float3 worldNormal = UnityObjectToWorldNormal(v.normal);
                float3 worldTangent = UnityObjectToWorldDir(v.tangent.xyz);
                float3 worldBinormal = cross(worldNormal, worldTangent) * v.tangent.w;

                o.TtoW0 = float4(worldTangent.x, worldBinormal.x, worldNormal.x, o.pos.x);
                o.TtoW1 = float4(worldTangent.y, worldBinormal.y, worldNormal.y, o.pos.y);
                o.TtoW2 = float4(worldTangent.z, worldBinormal.z, worldNormal.z, o.pos.z);
                return o;
            }

            fixed4 frag (v2f i) : SV_Target
            {
                fixed4 albedo = tex2D(_MainTex, i.uv.xy);

                float3 worldPos = float3(i.TtoW0.w, i.TtoW1.w, i.TtoW2.w);
                float3x3 TtoW = float3x3(i.TtoW0.xyz, i.TtoW1.xyz, i.TtoW2.xyz);

                float3 tangentNormal = UnpackNormal(tex2D(_BumpMap, i.uv.zw));
                tangentNormal.xy *= _BumpScale;   // 控制凹凸强度
                tangentNormal = normalize(tangentNormal);

                float3 worldNormal = normalize(mul(TtoW, tangentNormal));

                float3 L = normalize(UnityWorldSpaceLightDir(worldPos));
                float NdotL = saturate(dot(worldNormal, L));
                fixed3 diffuse = _LightColor0.rgb * albedo.rgb * NdotL;

                return fixed4(diffuse, 1.0);
            }
            ENDCG
        }
    }

    Fallback "Diffuse"
}
```text

要点回顾：把世界坐标塞进 TtoW 的 `.w` 分量，是为了节省插值器；`UnpackNormal` 解包；`mul(TtoW, tangentNormal)` 完成切线→世界变换。

## 七、URP 下的法线贴图

URP 的 `Core.hlsl` 提供了更省事的宏：

```hlsl
float sgn = IN.tangentWS.w;
float3 bitangent = sgn * cross(IN.normalWS.xyz, IN.tangentWS.xyz);
IN.normalWS = TransformTangentToWorld(normalTS, half3x3(IN.tangentWS.xyz, bitangent.xyz, IN.normalWS.xyz));
```text

其中 `TransformTangentToWorld` 内置了 TBN 变换，比手拼矩阵更简洁。手写时建议优先用 URP 提供的宏。

## 八、mipmap、滤波与各向异性

- **mipmap**：同一纹理预生成的一系列缩小版本。物体离远时采样小尺寸版本，减少闪烁和带宽。法线贴图同样会生成 mipmap。
- **滤波（Filtering）**：决定采样多个纹素时怎么平均。`Point`（最邻近，马赛克）vs `Bilinear`（双线性，平滑）vs `Trilinear`（加上 mipmap 间插值）。
- **各向异性（Anisotropic）**：处理"斜着看地面/墙面"时的模糊，角度越大越清晰，代价也越高。

这些在纹理的 Import Settings 里设置，Shader 采样时会自动应用；高级场景可用 `tex2Dlod` 手动指定 mip 级别。
